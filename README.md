# 字幕时间轴修复器

本地运行的字幕时间轴修复工具（React + TypeScript + Vite）。导入 SRT 字幕与本地视频后，可在播放器下方的时间轴上直接拖动字幕块调整起止时间，对照自动生成的音频波形精确定位人声，实时检测时间重叠、起止倒置、时长过短等问题，修复完成后导出标准 SRT。

## 功能

- 📄 **导入 SRT / 本地视频**：视频仅通过 `URL.createObjectURL` 在本地播放，不上传任何数据
- 🌊 **音频波形轨道**：导入视频后在浏览器内用 Web Audio API 解码音轨，按固定时间桶提取正/负峰值，绘制在标尺与字幕块之间，与刻度、播放头共用同一时间坐标；缩放 / 横向滚动时只渲染可视区；解码失败可关闭提示，不影响字幕编辑；波形仅驻留内存，切换视频自动释放
- 🧱 **时间轴编辑**：播放器下方按时间轴展示字幕块
  - 拖动块体：整体平移该条字幕
  - 拖动左右两端手柄：分别调整开始 / 结束时间
  - 点击标尺或轨道空白处：移动播放头并联动视频跳转
  - 双击字幕块：跳转到该字幕开始时间
- 🔗 **连锁移动**：开启后，平移某条字幕时其后所有字幕保持相对间隔同步平移
- 🚦 **实时问题检测**（字幕块与右侧面板同步高亮）
  - 红色：时间重叠
  - 紫色（斜纹）：起止倒置（结束 ≤ 开始）
  - 黄色：时长短于 500ms
- ↶↷ **撤销 / 重做**：拖动、删除等操作均可回退
- ⚓ **双锚点漂移校准**：整稿时间随播放进度线性漂移（开头差 0.5s、结尾差 3s 之类）时，选择两条锚点字幕并填写各自与视频对齐的目标开始时间，系统按「锚点 A 之前统一偏移 → 两锚点间按原始开始时间线性插值 → 锚点 B 之后统一偏移」平移整批字幕，所有字幕时长不变；锚点须按当前时间先后排列且目标时间递增，否则禁用应用并提示原因；应用前预览受影响条数与最大偏移，整批作为一次撤销/重做
- 📚 **修订稿合并**：当前字幕已加载时，可再导入一份 SRT 作为修订稿（不替换当前时间轴）。系统按「文本相似度 0.6 + 时间区间 IoU 0.4」加权打分，用动态规划求保持顺序的一对一最大总分匹配，侧栏预览每对的当前/修订文本、得分及两侧未匹配项；应用时仅把已匹配的修订文本写回当前字幕（保留 id、序号与时间），整批可一次撤销/重做
- 🔇 **静音吸附**：音频波形就绪后，选择一段**连续字幕区间**并设置峰值阈值、最短静音长度、最大吸附距离与字幕最小时长。系统以每个波形桶的 `max(|min|, |max|)` 判定静音、合并连续命中桶并取区间中点，为各字幕起止时间生成原位置与距离内的静音候选，再用动态规划在「保持条目顺序、每条时长达标、互不重叠」约束下依次最大化吸附边界数、最小化总位移（同分取时间序列字典序较小者）；侧栏预览原/新时间与对应静音段，无可行方案时禁用应用，整批作为一次撤销/重做
- 💾 **导出修复后的 SRT**：按开始时间排序并重新编号

## 快速开始（Docker，单条命令）

```bash
docker compose up --build
```

启动后在浏览器访问：

> **http://localhost:8080**

（容器内 Nginx 监听 80 端口，Compose 映射到宿主机 **8080** 端口；如需修改，调整 `docker-compose.yml` 中的 `ports`。）

停止服务：

```bash
docker compose down
```

## 本地开发

```bash
npm install
npm run dev
```

开发服务器地址：**http://localhost:5173**

## 使用说明

1. 点击 **导入 SRT** 选择字幕文件（或先点 **加载示例** 体验，示例故意包含三类问题）。
2. 点击 **导入视频** 关联本地视频（可选，不导入也能编辑时间轴）；导入后自动解码音轨，在标尺与字幕块之间显示音频波形。
3. 在时间轴上拖动字幕块或其两端手柄修复问题；右侧「问题检测」面板实时刷新，点击条目可跳转定位。
4. 需要整体后移/前移某段字幕时，打开 **连锁移动** 再拖动即可。
5. 需要套用另一份修订后的 SRT 文本时，点击工具栏 **修订稿合并** 打开右侧侧栏（详见下文）。
6. 整稿时间随播放进度逐渐漂移时，点击工具栏 **漂移校准** 打开双锚点校准侧栏（详见下文）。
7. 导入含音轨的视频、波形显示后，可点击工具栏 **静音吸附**，把字幕起止边界自动对齐到附近的静音间隙（详见下文）。
8. 修复完成后点击 **导出修复后 SRT** 下载文件（文件名自动加 `.fixed` 后缀）。

### 双锚点漂移校准侧栏

入口：工具栏的 **⚓ 漂移校准** 按钮（需先导入当前字幕，否则按钮禁用；与修订稿合并侧栏互斥）。

适用于整稿字幕与视频之间存在「渐进式漂移」的场景：开头只差零点几秒，越往后差得越多，单点整体平移无法对齐。

1. 分别在 **锚点 A**、**锚点 B** 的下拉框中各选一条字幕（按当前开始时间排序列出，含序号、时间与文本预览）；目标时间留空时会自动预填该字幕的当前开始时间，便于微调。
2. 为每条锚点填写它与视频对齐后的**目标开始时间**，支持 `83.5`（秒）、`02:05`（分:秒）、`00:01:23,500`（时:分:秒,毫秒）等格式；也可以先把视频播放到对齐位置，再点 **⏱ 播放头** 一键填入当前播放头时间。
3. 系统据此为每条字幕计算偏移：
   - 锚点 A 之前（含）：统一使用锚点 A 的偏移；
   - 两锚点之间：按**原始开始时间**在两个锚点偏移间线性插值；
   - 锚点 B 之后（含）：统一使用锚点 B 的偏移；
   - 所有字幕**时长保持不变**（起止时间同步平移）。
4. 锚点须按当前时间先后排列（A 的开始时间早于 B），目标开始时间也须递增；不满足、锚点缺失、目标时间无法解析、平移后有字幕越过 0 点或无需校准时，**应用** 按钮禁用并显示具体原因。
5. 应用前侧栏实时预览 **受影响条数** 与 **最大偏移**；点 **应用校准** 后整批平移作为**一次撤销/重做**操作（`Ctrl/Cmd+Z` 即可整体回退）。重新导入字幕会自动清空锚点表单。

### 修订稿合并侧栏

入口：工具栏的 **📚 修订稿合并** 按钮（需先导入当前字幕，否则按钮禁用）。

1. 在侧栏点 **导入修订稿** 选择另一份 SRT。修订稿只作为文本来源，**不会替换当前字幕的时间轴、id 与序号**。
2. 两侧文本先转小写、去首尾空白并折叠连续空白，再按 Unicode 字符数计算 Levenshtein 编辑距离：
   - 文本得分 = `1 − 编辑距离 / max(两侧字符数, 1)`
   - 时间得分 = 两条字幕毫秒区间的 IoU（交并比），无有效交集（含区间倒置、仅端点相接）时为 0
   - 综合得分 = `0.6 × 文本 + 0.4 × 时间`，仅保留综合得分 ≥ **0.45** 的候选对
3. 用动态规划在「匹配 / 跳过修订稿 / 跳过当前稿」三种转移中求**保持顺序的一对一最大总分匹配**；同分时依次优先：匹配 → 跳过修订稿 → 跳过当前稿。
4. 侧栏预览每对匹配的当前/修订文本、综合得分（悬停可看文本、时间分项）与时间；下方分组列出两侧的未匹配条目（点击当前稿条目可跳转定位）。
5. 点 **应用合并** 后，仅把已匹配条目的修订文本写回当前字幕，**id、序号、起止时间全部保留**，修订稿中未匹配的条目不写入；整批写入作为**一次撤销/重做**操作（`Ctrl/Cmd+Z` 即可整体回退）。重新导入当前字幕会自动清空修订稿。

### 静音吸附侧栏

入口：工具栏的 **🔇 静音吸附** 按钮。**仅在音频波形就绪时可用**（需先导入字幕与含音轨的视频，且波形解码完成；解码中 / 失败 / 未导入视频时按钮禁用）。与其他侧栏互斥。

适用场景：字幕边界与人声起止错开、边界落在说话中间，希望批量把开始/结束时间对齐到句子之间的静音间隙。

1. 在 **区间起始字幕 / 区间结束字幕** 两个下拉框中各选一条（按当前开始时间排序列出），系统按时间排序取两者之间的**连续区间**（含两端，顺序选反也可以）；也可点 **全选 N 条** 一键覆盖全部字幕。只有区间内条目的时间会被调整。
2. 设置四个参数：
   - **峰值阈值**（默认 2%）：波形桶的峰值 `max(abs(负峰), abs(正峰))` 不高于该值才判为静音桶，滑块范围 0–50%；
   - **最短静音长度**（默认 150ms）：连续静音桶合并后，时长不足此值的段被丢弃；
   - **最大吸附距离**（默认 500ms）：只有距边界原位置在此范围内的静音点才会成为候选；
   - **字幕最小时长**（默认 300ms）：吸附后每条字幕时长不得短于该值。
3. 静音段的吸附点取整段的**中点**（段起点/终点按桶边界计算，中点四舍五入）。
4. 对区间内每条字幕的开始、结束边界，候选时间 = **原位置**（不吸附）+ 距离内的全部静音中点；动态规划在候选间选择，硬约束为：
   - 保持字幕条目顺序，相邻条目**互不重叠**（允许端点相接）；
   - 每条字幕时长 ≥ **字幕最小时长**，且边界时间不早于 0。
   优化目标依次为：**① 吸附边界数最多 → ② 所有边界总位移最小 → ③ 同分时取完整新时间序列字典序较小者**。
5. 侧栏实时预览：汇总吸附边界数 / 改动条数 / 总位移 / 最大位移；每条列出原时间（删除线）⇒ 新时间、吸附的始/末标记及对应静音段（中点、静音时长、本条偏移）。点击条目可跳转定位。
6. **无可行方案**（当前阈值下无足够长的静音段，或最小时长 / 互不重叠约束在候选空间内无法满足）时，**应用** 按钮禁用并显示具体原因；距离内没有静音中点（方案零吸附）时同样禁用，可增大吸附距离或调低阈值再试。
7. 点 **应用吸附** 后仅写入区间内条目变化的起止时间（id、序号、文本、区间外字幕均不变），整批作为**一次撤销/重做**操作（`Ctrl/Cmd+Z` 即可整体回退）。重新导入字幕会自动重置区间与参数。

### 音频波形轨道

- 解码完全在浏览器内进行（Web Audio API `decodeAudioData`），文件不经过任何服务器；解码期间波形轨道显示忙碌动画。
- 波形按固定时间桶（10ms，超长音频自动增大桶长以控制内存）统计每个桶的正/负峰值，与刻度、字幕块、播放头共用同一时间坐标（`秒 × 缩放`），拖动缩放滑块或横向滚动时仅重绘可视区。
- 若文件无音轨、格式不受支持或解码失败，波形轨道内会显示可关闭的提示，字幕编辑不受影响；重新 **导入视频** 即可重试。
- 波形数据只保存在内存中，切换视频时自动释放旧数据（峰值数组随状态替换回收，解码用 `AudioContext` 即完即关）。

## 项目结构

```
├── Dockerfile              # 多阶段构建：node 构建 → nginx 托管
├── docker-compose.yml      # 单条命令启动，映射 8080:80
├── nginx.conf              # SPA 回退与静态资源缓存
├── index.html
├── package.json
├── vite.config.ts
└── src
    ├── App.tsx             # 主状态、撤销/重做历史栈、导入导出
    ├── srt.ts              # SRT 解析 / 序列化 / 时间戳格式化 / 目标时间输入解析
    ├── issues.ts           # 重叠、倒置、过短（<500ms）实时检测
    ├── merge.ts            # 修订稿合并：文本归一化、编辑距离、区间 IoU、阈值过滤与顺序保持一对一 DP 匹配
    ├── drift.ts            # 双锚点漂移校准：锚点校验、分段线性插值偏移方案、整批平移
    ├── silence.ts          # 静音吸附：静音桶扫描与段合并、边界候选、顺序/时长/不重叠约束下的三级目标 DP
    ├── sample.ts           # 内置示例字幕
    ├── waveform.ts         # Web Audio 解码 + 固定时间桶正/负峰值计算
    ├── useWaveform.ts      # 波形解码状态机（idle / decoding / ready / error）
    └── components
        ├── Toolbar.tsx      # 导入/导出、撤销重做、连锁移动、缩放、修订稿合并/漂移校准/静音吸附入口
        ├── VideoPlayer.tsx  # 本地视频播放器
        ├── Timeline.tsx     # 时间轴：拖动/缩放手柄、标尺、播放头、波形轨道
        ├── WaveformLane.tsx # 波形轨道：Canvas 只渲染可视区，忙碌/错误提示
        ├── IssuesPanel.tsx  # 问题列表面板
        ├── RevisionMergePanel.tsx # 修订稿合并侧栏：导入、匹配预览、未匹配项、应用合并
        ├── DriftPanel.tsx   # 双锚点漂移校准侧栏：锚点选择、目标时间、预览与应用
        └── SilencePanel.tsx # 静音吸附侧栏：连续区间、阈值/静音长度/吸附距离/最小时长、原/新时间与静音段预览
```
